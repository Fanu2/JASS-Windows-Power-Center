# JASS JSON Explorer v1.0

A lightweight local JSON viewer, editor, formatter and search tool built with PySide6.

## Features

- Open `.json` files
- Create new JSON documents
- Edit JSON directly
- Tree view of objects and arrays
- Shows JSON value types
- Shows compact value previews
- Search keys and values
- Find / Find Next
- Case-sensitive search option
- JSON validation
- Pretty formatting
- Compact/minified formatting
- Save and Save As
- Selected-value viewer
- Copy selected value
- Unsaved-change protection
- UTF-8 JSON support
- Dark JASS interface

## Requirements

- Windows
- Python 3.10+
- PySide6

Install PySide6 if required:

```powershell
py -m pip install PySide6
```

## Run

```powershell
py .\JASS_JSON_Explorer_v1.0.py
```

## Safety

The application works only with the JSON file you explicitly open or save. It does not modify other files or folders.

When editing an existing file, use **Save As** if you want to preserve the original.

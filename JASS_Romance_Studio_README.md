# JASS Romance Studio v1.0

A private, local-first romantic interactive-fiction and creative-writing studio.

## Features

- Character creator
- Relationship setting
- Romantic scene builder
- Multiple settings and scene types
- Mood dial:
  - Tender
  - Romantic
  - Flirty
  - Sensual
  - Intimate
- Romantic tension control
- Interactive story continuation
- "Suggest What Happens Next"
- Romance prompt deck
- Love-letter generator
- Date-idea generator
- Scene history
- Save/load `.jrs.json` story files
- Export stories to TXT
- Completely local
- No AI service required
- Dark JASS interface

## Content Design

The app is designed for adult romantic/sensual creative writing and keeps the v1.0 experience focused on romance, atmosphere, dialogue, affection and relationship tension rather than explicit sexual content.

## Requirements

- Windows
- Python 3.10+
- PySide6

Install:

```powershell
py -m pip install PySide6
```

## Run

```powershell
py .\JASS_Romance_Studio_v1.0.py
```

## Story Files

Stories are saved as:

```text
.jrs.json
```

They are ordinary JSON files and can be backed up or moved between computers.

## Privacy

The application is local-first. No story content is transmitted to an online service.

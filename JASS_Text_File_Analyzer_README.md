# JASS Text File Analyzer v1.0

Lightweight text-analysis utility built with PySide6 and Python's standard library.

## Features

- Open TXT, Markdown, LOG and many other text files
- Automatic encoding detection
- File size
- Line count
- Non-empty and empty line counts
- Word count
- Unique word count
- Character count
- Character count without whitespace
- Paragraph count
- Average line length
- Longest and shortest line
- Duplicate-line detection
- Most frequent words
- Text viewer with line-preserving display
- Normal text search
- Case-sensitive search
- Regular-expression search
- Match highlighting
- Export TXT report
- Export JSON report
- Export CSV report
- Background analysis
- Read-only operation
- Dark JASS interface

## Requirements

- Windows
- Python 3.10+
- PySide6

Install:

```powershell
py -m pip install PySide6
```

## Run

```powershell
py .\JASS_Text_File_Analyzer_v1.0.py
```

## Safety

The source text file is never modified. Analysis is performed locally.
